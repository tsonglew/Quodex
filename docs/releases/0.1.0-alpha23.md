# Quodex 0.1.0-alpha23

- 设置 → 桌面额度图标 → 添加到桌面，可在流线 Q logo 上查看剩余百分比，点击打开 Quodex。
- 支持短周期／每周选择，独立于页面的已用／剩余偏好；关闭百分比后恢复普通 logo。
- 示例、旧数据、受限、未知与未连接均有标记，不根据缺失数据或重置时钟推算额度。
- 图标随前台、组件和后台额度刷新更新，与小组件共享一个周期任务；没有额度入口时停止轮询。
- 版本递增至 23，沿用 Quodex 包名和签名发布流程。添加与刷新支持程度由 Launcher 决定，厂商桌面仍需真机验收。

本版为实验性预发布，支持 Android 10 及以上。真实账号、OEM 与长期后台验收继续独立跟踪；正式 APK、SHA256SUMS 和来源以同一 GitHub Release 的附件为准。
