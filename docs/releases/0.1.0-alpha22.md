# Quodex 0.1.0-alpha22

- 采用深海青浅深色主题和流线 Q 图标，更新 Android 自适应图标与桌面组件预览。
- 重新整理额度概览、小组件和设置页，保留各页滚动位置、趋势周期及大字体布局。
- 增加页面淡入、连接按钮扫光与按压回弹、额度条平滑填充、Token 柱条错峰展开。遵循系统动画时长缩放，关闭动画后直接显示完整内容；百分比和无障碍描述始终采用实际数据。
- Token 总量支持易读单位切换，保留逐日明细、缺失数据与真实零值的区别。
- Android 版本号递增至 22，沿用现有包名与正式签名，供已安装正式版覆盖更新。

本版是预发布版，支持 Android 10 及以上。Codex 登录与用量接口仍为实验性兼容接入，真实账号、厂商桌面和长期后台行为继续验收。App 仅读取额度与用量统计，不执行模型请求。

安装包、SHA256SUMS 与 provenance.json 由完整 CI 和固定签名流程生成；请以同一 Release 的附件核对版本与来源。调试包与正式包签名不同。
