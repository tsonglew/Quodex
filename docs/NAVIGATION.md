# 导航与页面职责整理

2026-11-06，基于 alpha35 / `4a9dec4` 的导航改动；[PR #58](https://github.com/tsonglew/Quodex/pull/58) 记录合并状态，安装包以 Releases 实际发布为准。

## 页面职责

| 入口 | 内容 | 明细与操作 |
| --- | --- | --- |
| 总览 | 仅已连接服务的关键指标；无 Codex 也能展示其他服务 | 点服务标题查看完整用量。Codex 的 Token 趋势和重置卡保留在详情中 |
| 账号 | Codex、DeepSeek、OpenCode Go、OpenCode Zen、Cursor 的连接状态 | 选择服务连接、重连或断开；Codex 退出从设置迁至这里 |
| 设置 | 外观、语言、Codex 剩余显示、刷新、桌面展示、更新、帮助七项紧凑入口 | 长说明、选项和预览放在二级页 |

桌面小组件与额度图标共用“设置 → 桌面展示”入口。保留独立小组件配置；应用内全局显示开关仍只影响 Codex 额度及其额度组件。后台间隔说明明确仅作用于 Codex。

总览保留不同单位：DeepSeek 按币种展示余额，Zen 优先展示可用额度，Go 展示滚动与周用量，Cursor 保留两个模型用量池；完整字段留在详情。未知数据不补零，不合并不同币种或百分比，不推算费用。

首次进入应用或账号页会检查已连接服务，仍遵循五分钟缓存和原重试策略；首页刷新会刷新已连接服务。示例模式无真实额度请求。各页面独立保留滚动位置；切换标签保留详情，再点当前标签或按返回回到目录。热力图组件继续直接进入 Codex 的 30 天趋势。

冷启动总览等待本机订阅存储读取后才判断是否没有连接；读取失败显示存储错误，已有 Codex 摘要不受等待影响。热力图入口及恢复的 Codex 详情同样等待账号初始化，避免向已连接用户短暂显示连接与示例提示。
