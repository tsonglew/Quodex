Quodex プライバシーについて
更新日：2026 年 11 月 6 日

Quodex は、Codex の使用枠とホーム画面ウィジェット、および DeepSeek、OpenCode、Kimi、WorkBuddy、Cursor、Grok の残高やプラン使用量を確認するための独立したサードパーティ製 Android ツールです。各サービス提供者との提携関係はありません。互換接続機能は現在、実験段階です。

接続とネットワーク通信
ログインは OpenAI のページで行います。Quodex にアカウントのパスワードを入力する必要はありません。アプリは auth.openai.com にデバイス認証、トークン交換、更新のリクエストを送り、chatgpt.com から使用枠とアカウント全体のトークン使用量統計を取得します。リクエストには、対応するログインコード、認証コードまたはトークン、アカウント識別子、IP アドレスなどの一般的なネットワーク情報が含まれます。ブラウザーのログインページにおけるデータの取り扱いは、そのページの提供者が管理します。
アプリは接続を使用枠とトークン使用量統計の取得にのみ利用し、チャットやモデル生成のリクエストは送信しません。認証情報には、より広い機能への権限が含まれる場合があり、読み取り専用の認証情報とはみなせません。ログインコードやトークンを他人に渡さないでください。

その他のプランサービス
Kimi、WorkBuddy、Grok／Cursor はアプリ内の公式 HTTPS ログインページを使います。パスワード、認証コード、確認操作は提供者のページで入力し、Cookie・トークン・JSON の貼り付け欄はありません。認証サイトに移動する場合は、そのサイトの規則が適用されます。確認を自動回避せず、一部の外部ログイン方法は埋め込みブラウザーに対応しない場合があります。WorkBuddy は国際サイトのみ対応し、移行済み Cursor は Grok／Cursor 共通枠を使用します。
各サービスは独立した Android WebView プロセスと専用ブラウザー領域を持ち、Cookie、ローカルストレージ、ページキャッシュ、関連認証サイトの状態を今後の自動更新や手動更新に利用します。他のブラウザーのログイン情報は読みません。この領域は WebView がアプリ専用ストレージで管理し、以下の API キー用 AES-GCM ファイルとは別です。Android のバックアップと端末移行は無効です。ログイン画面を閉じても状態を保持します。「接続解除」、または未接続時の「ログイン状態を消去」は対応する Cookie、ウェブストレージ、キャッシュを消去し、他のサービスには影響しません。
ログイン後、固定ドメイン内で使用枠を読み取ります：www.kimi.com/apiv2/kimi.gateway.membership.v2.MembershipService/GetSubscriptionStats、www.workbuddy.ai/billing/meter/get-user-resource、grok.com/dashboard/api/dashboard/ 配下の v2/usage-status と get-complat-credit-balance。ページ自身の認証状態を使い、Cookie、access_token、パスワードはメインプロセスに返しません。解析した使用枠、費用、期間、取得時刻のみを暗号化スナップショットに保存します。ウェブログインはアプリ起動・復帰時に5分間のキャッシュを確認し、前面表示中も定期的に更新します。保存済みログインを再利用し、ウェブ画面は表示しません。各読み取りには時間制限があり、アプリが前面を離れると自動取得を停止します。手動更新も同じ経路を使います。ログイン切れやサイト認証が必要な場合は自動取得を一時停止し、公式ログインでの操作を案内します。失敗時は以前の値と時刻を保持し、429 は Retry-After に従います。旧手動取り込みのデータも保持し、公式ログインで更新できます。
開発者 API は別のキーを使用します。DeepSeek は api.deepseek.com/user/balance、OpenCode は opencode.ai/zen/go/v1/usage または opencode.ai/console/api/billing/status、Kimi Code は api.kimi.com/coding/v1/usages のみに送信します。国内／国際 Kimi API は api.moonshot.cn／api.moonshot.ai の /v1/users/me/balance を使い、地域間の代替接続は行いません。xAI チーム Management キーは management-api.x.ai で確認と前払残高取得に使い、チーム識別子は保存しません。Cursor チーム Admin キーは api.cursor.com/teams/spend のみで Basic 認証を使い、全ページの費用を集計してメンバーの名前・メール・識別子を保存しません。旧 Kimi、WorkBuddy、Cursor、Grok セッションは公式ログインで置き換えるまで固定ドメインへの読み取りを維持します。旧 Cursor と共通枠は個別に解除します。
API キー、旧セッション認証情報、対応するスナップショットは Android Keystore と AES-GCM で暗号化し、バックアップ対象外の専用領域に保存します。API 応答原文は保存・ログ記録しません。API と旧接続はアプリやアカウント画面を開く際に 5 分キャッシュで確認でき、手動更新も可能です。一時障害は最大 3 回試行し Retry-After に従います。使用枠の取得は読み取りのみで、生成・支払い・入金・プラン変更は行いませんが、認証情報自体には広い権限があり得ます。提供者には IP アドレスなど通常の通信情報が送信されます。バックグラウンド処理、ウィジェット、サービス間のアカウント統合は追加しません。サンプルは通信しません。
接続解除は選択したローカル接続とデータを削除し、Codex のログアウトは Codex のみが対象です。読み取れないプラン保存領域を確認後にリセットする場合、この三つのブラウザー状態も消去します。公式ダッシュボードは外部ブラウザーで開き、アプリ内とログインを共有せず、外部ブラウザーの状態は消去しません。リモートのキーやセッションは提供者の設定で失効させてください。

更新の確認と通知
使用枠、トークン統計、更新確認、APK ダウンロードの一時的な障害は、サーバーの待機指示に従って回数を制限して再試行します。キャンセルすると現在の処理を停止します。中断した APK は最初からダウンロードし直すため、通信量が増える場合があります。再試行の期限を端末内に保存する場合があります。再試行によって新たな送信先や送信データの種類が追加されることはありません。

自動更新確認は初期状態で有効です。アプリを開いたときに所定の間隔で確認し、バックグラウンドでは 12 時間ごとの確認を目標とします。実際のタイミングは、システムの実行制御、通信状況、省電力設定に左右されます。アプリはまず raw.githubusercontent.com から公開リリース時に生成された Quodex の更新インデックスを取得します。接続エラーまたはタイムアウト時のみ api.github.com の公開 Releases を予備として確認します。待機時刻は更新元ごとに保存します。GitHub には IP アドレスと一般的なクライアントヘッダーが送られますが、Codex の認証情報、アカウント、使用枠、端末識別子は含まれません。署名とバージョンの比較は端末内で行い、インストール証明書は送信しません。「設定 → アプリの更新」で自動確認を無効にできます。無効にした後は、「更新を確認」を押した場合のみ通信します。通知が許可されている場合、新しいバージョンを端末内で通知し、通知を押すとアプリが開きます。
「更新をダウンロードしてインストール」を選ぶと、github.com と公開ファイル用ドメイン release-assets.githubusercontent.com、objects.githubusercontent.com から公開 APK をダウンロードします。これらのリクエストにも、Codex の認証情報、アカウント、使用枠、端末識別子は含まれません。APK はアプリ専用のキャッシュに一時保存します。ハッシュ、パッケージ名、バージョン、署名を検証してから、Android のインストール画面を開きます。初回はこの提供元からのインストールを許可する必要がある場合があります。インストールには必ず Android の画面で利用者の確認が必要で、無確認でインストールすることはありません。失敗またはキャンセルしたダウンロードの未完成ファイルは削除します。完成した APK のキャッシュは、後続のダウンロードやシステムのキャッシュ消去時に削除されます。
端末には、更新設定、直近の試行と成功した確認の時刻、見つかった公開バージョン情報、通知済みのバージョン番号も保存します。新しいバージョンごとに一度通知します。通知を拒否しても、アプリ内で更新を確認できます。

端末内の保存
アクセストークン、更新トークン、アカウント識別子、有効期限は、Android Keystore の鍵と AES-GCM を使って暗号化し、アプリ専用領域に保存します。使用枠のスナップショット、期間、リセット時刻、アカウント識別子、取得成功時刻は端末内のデータベースに保存します。表示設定、ウィジェット設定、直近の試行、エラーの種類は端末内の設定に保存します。言語設定は Android または AndroidX が端末内に保存し、アプリ、ウィジェット、通知に使用します。言語の選択をアカウントサービスに送信することはありません。使用枠とトークン使用量のキャッシュは、暗号化データベースではありません。
トークンの推移は chatgpt.com/backend-api/wham/profiles/me から日別使用量、累計使用量、1 日の最大値を取得します。必要な統計とデータ時刻のみを読み取り、このエンドポイントから返される氏名、ユーザー名、プロフィール、エラーの原文は保存しません。統計は現在のアカウントの使用枠とともに端末内に保存し、最後に取得できた日付と数値を保持します。アカウントの切り替え、接続の解除、サンプルモードへの移行では、実際の統計を消去または分離します。データのない日をゼロとはみなさず、使用枠の割合からトークン数、料金、入力・出力の内訳を推定しません。
リセットカードの利用可能数は使用枠の取得時に読み取ります。「詳細を見る」を開くと、同じアカウントの認証情報を使い chatgpt.com/backend-api/wham/rate-limit-reset-credits に読み取り専用の GET リクエストを送ります。カードの識別子、種類、状態、名称、説明、付与日時、有効期限、利用可能数と取得時刻を、現在のアカウントの使用枠とともに端末内の暗号化されていないデータベースに保存します。診断本文には記録しません。詳細は 5 分間キャッシュし、手動でも更新できます。一時的な障害は回数を制限して再試行し、Retry-After に従います。詳細のバックグラウンド取得やカードの使用は行いません。接続解除、アカウント変更、サンプルモードへの移行時に、実際のカード情報を消去または分離します。
Android のバックアップと端末移行用バックアップは無効で、端末間の同期は行いません。データは次回の起動やバックグラウンド更新に備えて保持し、後のスナップショットによる置き換え、または消去操作まで残ります。

ホーム画面への表示
ウィジェットはホームアプリに使用枠、状態、更新時刻を提供します。トークンヒートマップは日別使用量のグラフ、報告された日別使用量の合計、記録日も提供します。このウィジェットを配置している間は、バックグラウンド同期でトークン統計を取得し、個別のキャッシュとレート制限に従います。ホーム画面を見られる人は、これらの情報を読むことができます。プライバシー上の必要に応じて、追加するかどうかを判断してください。
使用枠アイコンを追加すると、残りの割合を表示する画像と期間・状態の説明をホームアプリに提供し、使用枠の取得に合わせて更新します。アカウント識別子や認証情報は含まれません。ホームアプリはショートカットとアイコンのキャッシュを保存します。割合の表示を無効にすると通常のロゴへの復元を要求し、接続を解除すると未接続表示への変更を要求します。表示とキャッシュの管理はホームアプリ側で行います。プライバシー上の必要に応じて、アイコンを追加するかどうかを判断してください。

診断と共有
アプリには、広告、リモートの利用分析、自動クラッシュ報告、Quodex 独自のデータサーバーはありません。アプリ専用領域に直近 200 件の診断イベントと 7 日分の時間別統計を循環保存します。内容には、リクエストの種類と回数、HTTP ステータス、更新確認の結果と再試行可能時刻、ネットワーク障害、未処理例外の種類とメインスレッド上かどうか（例外メッセージとスタックトレースは含みません）、スナップショットの保存成功回数と成功間隔の最大値、更新結果、スキップ理由、所要時間、キャッシュの経過時間、バックグラウンド処理、ウィジェット更新、ページの状態、画面サイズ、文字の倍率が含まれます。トークン、アカウント識別子、使用枠の数値、レスポンス本文は記録しません。
設定から記録を消去したり、内容を確認して Android の共有機能で診断レポートを送ることができます。レポートには、アプリと Android のバージョン、ネットワークの利用可否、省電力状態、バックグラウンド制限の有無、バックグラウンド処理の状態も含まれます。共有先は利用者が選択し、自動送信は行いません。連絡先、位置情報、チャット内容は読み取りません。認証情報、アカウント、使用枠を GitHub に自動送信することもありません。スクリーンショットや問題を送る前に個人情報を隠し、ログインコード、トークン、認証レスポンスの原文を添付しないでください。

消去と認可の取り消し
アカウント → Codex の「接続を解除して端末内のデータを消去」では、Codex のログインファイル、使用枠の記録、トークン使用量キャッシュを削除し、Codex の同期処理を取り消して、ウィジェットを未接続表示に戻します。他のサービスの接続と取り込みデータは保持されます。「プラン」の各カードで接続を解除すると削除できます。表示設定、ウィジェットのレイアウト、更新設定、公開リリースのキャッシュは保持します。バージョン確認はアカウントから独立しており、自動確認を別途無効にできます。アプリデータの消去またはアンインストールで端末内の記録を削除できます。接続の解除はサービス側の認可を取り消すものではなく、記憶媒体の物理的な完全消去を保証するものでもありません。サービス側の接続を取り消すには、アカウント提供者の管理機能を使用してください。

フィードバックと変更
問題は github.com/tsonglew/Quodex/issues から報告できます。公開の投稿に認証情報を含めないでください。今後サーバー、分析機能、新たなデータ用途を追加する場合は、先にこの説明とアプリの実装を更新します。

ChatGPT API クレジット：カードを展開すると、既存の Codex 認証情報を使い chatgpt.com/backend-api/product-account-links/accounts/{account_id}/benefits/chatgpt_api_credits_promo に読み取り専用 GET を送信します。対象資格、理由コード、特典額、受取可能額、通貨、周期、有効期限、取得日時をアカウントのスナップショットと共に本機の非暗号化データベースへ保存します。5 分間のキャッシュと Retry-After は通常の利用枠更新から独立しています。アカウント切替、ログアウト、デモモードでキャッシュを削除または分離します。バックグラウンドでの特典照会、受け取り、組織連携、請求変更、チャット読み取りは行いません。試験的なサービスでは Codex 認証が拒否されたりブラウザー確認が必要な場合があります。取得できない残高をゼロと推定しません。
